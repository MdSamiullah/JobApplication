SwiftLaTeX pdfTeX engine (WebAssembly), used unmodified for "Compile in this browser (experimental)".
Only loaded when someone chooses that option. Licensed under the GNU Affero General Public License v3
(LICENSE-SwiftLaTeX.txt). Source code of this exact version (release v20022022):
  https://github.com/SwiftLaTeX/SwiftLaTeX/releases/tag/v20022022
  https://github.com/SwiftLaTeX/SwiftLaTeX
It downloads the LaTeX packages a document needs from the SwiftLaTeX package mirror
(https://texlive2.swiftlatex.com/); the document itself stays in the browser.
